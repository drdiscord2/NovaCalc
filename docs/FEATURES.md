# NovaCalc — Список функций (FEATURES)

## Режимы
1. **Обычный** — базовая арифметика для повседневных расчётов.
2. **Инженерный** — научные функции, программирование, системы счисления.
3. **Лабораторный** — конвертеры, даты, статистика, константы.

Переключение мгновенное, состояние (выражение, Ans, память) сохраняется.

## Обычный режим
- Сложение, вычитание, умножение, деление;
- Проценты (семантика калькулятора Windows, см. ниже);
- Смена знака (±), x², √x, 1/x;
- Память: MC, MR, M+, M−, MS с индикатором;
- История вычислений (сохраняется между запусками, клик подставляет результат/выражение);
- Копирование результата и вставка из буфера обмена;
- Крупные кнопки, адаптивная компоновка.

## Инженерный режим
- Скобки и полный приоритет операций (парсер — рекурсивный спуск, не «наивная строка»);
- Степень `x^y`, `10ˣ`, `2ˣ`, `eˣ`;
- Корень n-й степени `root(x, n)`;
- `log` (по основанию 10), `ln`, `exp`;
- Факториал `n!`, модуль `abs(x)`;
- Тригонометрия: sin, cos, tan, asin, acos, atan, sinh, cosh, tanh;
- Переключатель Deg / Rad / Grad;
- Константы π и e;
- Экспоненциальная запись больших/малых чисел;
- Битовые операции: AND, OR, XOR, NOT, сдвиги влево/вправо;
- Системы счисления: DEC, HEX, OCT, BIN (ввод, вывод, конверсия);
- Переменная `Ans` (последний результат).

## Лабораторный режим
- Конвертер единиц: длина, масса, температура, объём, площадь, скорость, время, давление, энергия, мощность, информация/данные;
- Конвертер валют (офлайн, 8 валют: RUB, USD, EUR, CNY, KZT, BYN, GBP, JPY);
- Редактор пользовательских курсов валют с датой последнего изменения; опциональное онлайн-обновление только по нажатию;
- Физические константы (c, h, G, Nₐ, e-заряд, g и др.);
- Дата-калькулятор: разница между датами, прибавление/вычитание дней;
- Статистика по списку чисел: сумма, среднее, минимум, максимум, медиана, стандартное отклонение.

## Проценты (как в калькуляторе Windows)
| Выражение | Результат | Пояснение |
|---|---|---|
| `200 + 10%` | 220 | прибавить 10% от 200 |
| `200 - 10%` | 180 | вычесть 10% от 200 |
| `200 * 10%` | 20 | 10% от 200 |
| `200 / 10%` | 2000 | 200 ÷ 0.1 |
| `10%` | 0.1 | автономный процент = доля |

Логика встроена в парсер: правый операнд с постфиксным `%` трактуется относительно левого значения.

## Точность
- Базовая арифметика на `decimal` (до ~28–29 значащих цифр): `0.1 + 0.2 = 0.3` ровно;
- Транцендентные функции через `double` с аккуратным округлением отображения;
- Обработка ошибок: деление на ноль, переполнение, некорректный ввод, недопустимые операции — понятные сообщения без падений.

## Поддерживаемые языки интерфейса (12)
English, Русский (ru), Українська (uk), Қазақша (kk), Deutsch (de), Français (fr), Español (es), Italiano (it), Português (pt), Türkçe (tr), 中文 (zh), العربية (ar).

- Выбор языка в настройках, сохранение между запусками, автоопределение по системе при первом запуске;
- Fallback на English; переключение без перезапуска;
- Переводы — статичные, встроенные (`src/Localization/Strings.cs`), без внешних API.

## Горячие клавиши
Цифры 0–9, `+ - * /`, `.`/`,` , Enter (=), Backspace, Esc/Delete (C), Ctrl+C (копировать результат), Ctrl+Shift+C (копировать выражение), Ctrl+V (вставить), F9 (±), % (процент), ^ (степень), ↑/↓ (история), Ctrl+H (история), Ctrl+, (настройки).

## Интерфейс
Безрамочное окно со скруглёнными углами, градиентный фон, имитация акрила, тёмная тема по умолчанию + светлая (переключение без перезапуска), подсветка при наведении и эффект нажатия, собственные кнопки свернуть/закрыть, перетаскивание мышью, «поверх всех окон», поддержка DPI 100–175%.

## Хранение данных
Локальный JSON без реестра: `%APPDATA%\NovaCalc` или рядом с exe при наличии `portable.flag`. Безопасный запасной путь при read-only папке. Телеметрия отсутствует, фоновый интернет не используется.

## Самопроверка
`NovaCalc.exe --selftest` — ~77 проверок движка, конвертеров и локализации без открытия UI; код возврата 0 при успехе.
