# NovaCalc — Руководство пользователя

**NovaCalc — The Future of Calculation.**

Однофайловый калькулятор для Windows 10/11. Без установки, без интернета, без внешних зависимостей. Просто запустите `NovaCalc.exe`.

---

## 1. Запуск

Двойной клик по `NovaCalc.exe`. Готово — ничего устанавливать не нужно.

## 2. Режимы работы

Переключатель режимов — крупные кнопки в верхней части окна:

| Режим | Для кого | Что умеет |
|---|---|---|
| **Обычный** | Каждый день | + − × ÷, %, ±, x², √x, 1/x, память MC/MR/M+/M−/MS, история, копирование/вставка |
| **Инженерный** | Студенты, инженеры | Скобки и приоритет операций, x^y, 10ˣ, 2ˣ, eˣ, ⁿ√x, log, ln, exp, n!, |x|, sin/cos/tan и обратные/гиперболические, Deg/Rad/Grad, π, e, экспоненциальная запись, AND/OR/XOR/NOT/сдвиги, DEC/HEX/OCT/BIN, Ans |
| **Лабораторный** | Быт и лаборатория | Конвертер единиц (11 категорий), конвертер валют, физические константы, дата-калькулятор, статистика по списку чисел, редактор курсов валют |

Переключение режимов не сбрасывает текущее выражение, память и Ans.

## 3. Как считать

### Обычный режим (цепочечные вычисления)
Наберите `200 + 10` → нажмите `%` → `=`. Работает как в калькуляторе Windows:
- `200 + 10%` = **220** (прибавить 10% от 200);
- `200 - 10%` = **180**;
- `200 * 10%` = **20** (10% от 200);
- `200 / 10%` = **2000**;
- отдельное `10%` = **0.1**.

### Инженерный режим (полные выражения)
Можно набирать всё одной строкой с приоритетом операций и скобками:
```
2 + 2 * 2      = 6
(2 + 2) * 2    = 8
root(27, 3)    = 3        (кубический корень: root(число, степень))
sin(pi/2)      = 1        (при режиме Rad; в Deg: sin(90) = 1)
5!             = 120
Ans            = последний результат
```
Деление на ноль, переполнение и недопустимые операции (например, √−1) показываются аккуратной ошибкой — приложение не падает.

### Системы счисления
Выберите DEC/HEX/OCT/BIN — ввод и отображение переключаются. Поддержаны логические операции над целыми: `AND OR XOR NOT << >>`. Пример: HEX `1F` = DEC `31`.

### Память
- `MS` — сохранить в память;
- `MR` — вызвать из памяти;
- `M+` / `M−` — прибавить/вычесть текущее значение;
- `MC` — очистить. Индикатор `M` показывает, что память не пуста.

## 4. История

Панель истории справа (или `Ctrl+H`). Клик по записи подставляет её **результат**, двойной клик / Enter — **выражение** для повторного редактирования. Стрелки ↑/↓ — навигация по истории с клавиатуры. История сохраняется между запусками.

## 5. Клавиатура

| Клавиши | Действие |
|---|---|
| `0–9`, `.`, `,` | цифры и десятичный разделитель (`,` тоже принимается) |
| `+ - * /` | операции |
| `Enter` или `=` | вычислить |
| `Backspace` | стереть символ |
| `Esc`, `Delete` | сброс (CE → C) |
| `F9` | смена знака ± |
| `%` (Shift+5) | процент |
| `^` (Shift+6) | степень |
| `Ctrl+C` | копировать результат |
| `Ctrl+Shift+C` | копировать выражение |
| `Ctrl+V` | вставить из буфера |
| `Ctrl+H` | показать/скрыть историю |
| `Ctrl+,` | настройки |
| `↑` / `↓` | навигация по истории |

## 6. Настройки (`Ctrl+,`)

- **Тема**: тёмная (по умолчанию) / светлая — применяется мгновенно, без перезапуска;
- **Язык интерфейса**: 12 языков — мгновенное переключение;
- **Режим запуска**: обычный / инженерный / лабораторный;
- **Число отображаемых знаков**: до 28 значащих (движок считает на `decimal` до ~28–29 цифр; `0.1 + 0.2` даёт ровно `0.3`);
- **Всегда поверх окон**;
- **Разделители тысяч** и **экспоненциальная запись**;
- **Запоминать последний режим**.

## 7. Языки

English, Русский, Українська, Қазақша, Deutsch, Français, Español, Italiano, Português, Türkçe, 中文, العربية.

При первом запуске язык определяется по системе; если такого перевода нет — включается English. Пропущенные строки всегда показываются по-английски. Числа форматируются по локали, но математический движок от локали не зависит.

## 8. Валюты (офлайн)

Базовые валюты: RUB, USD, EUR, CNY, KZT, BYN, GBP, JPY. Курсы хранятся локально (`rates.json`), приложение работает без интернета. В редакторе курсов видно дату последнего изменения; курсы можно править вручную. Кнопка онлайн-обновления обращается в сеть **только по явному нажатию** и молча отказывается без сети.

## 9. Лабораторный режим подробно

- **Конвертер единиц**: длина, масса, температура, объём, площадь, скорость, время, давление, энергия, мощность, данные (байты). Примеры: `1 км = 1000 м`, `0 °C = 32 °F`.
- **Физические константы**: скорость света, постоянная Планка, число Авогадро, g, элементарный заряд и др. — вставляются одним кликом.
- **Дата-калькулятор**: разница между двумя датами (дни/недели/месяцы/годы) и прибавление/вычитание дней к дате.
- **Статистика**: список чисел через запятую → сумма, среднее, минимум, максимум, медиана, стандартное отклонение. Пример: `1,2,3,4,5` → среднее = 3.

## 10. Портативный режим

По умолчанию настройки и история хранятся в `%APPDATA%\NovaCalc` (реестр не используется). Если положить рядом с `NovaCalc.exe` пустой файл `portable.flag`, все данные будут храниться в папке рядом с exe — удобно для флешки. При недоступности папки программа использует безопасный запасной путь и не падает.

## 11. Самопроверка

```bat
NovaCalc.exe --selftest
```
Прогоняет ~77 встроенных тестов (арифметика, проценты, тригонометрия, системы счисления, конвертеры, статистика, локализация) без открытия интерфейса. Код возврата `0` — всё в порядке.

## 12. Приватность

Никакой телеметрии. Интернет не используется в фоне вообще. Все данные остаются на вашем компьютере.
