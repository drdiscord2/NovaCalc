# NovaCalc — План проекта (PLAN)

## Цель
Однофайловый калькулятор `NovaCalc.exe` для Windows 10/11 x64: скачал → запустил → работаешь. Без установки, без интернета, без браузерных технологий, без внешних runtime-DLL.

## Технологический стек
C# + .NET Framework 4.8 + WinForms. .NET Framework 4.8 встроен в Windows 10/11, поэтому пользователь не устанавливает ничего.

## Архитектура
```
src/
  Program.cs        — точка входа, разбор --selftest
  Engine/           — Lexer, CalculatorEngine (рекурсивный спуск), Value, AngleMode, исключения
  Converters/       — UnitConverter (11 категорий), CurrencyService, Helpers (системы счисления, статистика, даты)
  Services/         — StorageService (JSON-настройки/история/курсы), MiniJson (свой парсер без зависимостей), SelfTest
  Localization/     — Strings.cs — 12 языков, fallback en, детект системного языка
  Themes/           — Theme.cs — тёмная/светлая палитры, градиенты
  UI/               — MainForm (безрамочное окно, 3 режима, история, DPI), Controls (скруглённые кнопки), Dialogs (настройки, курсы, ошибки)
Resources/          — иконки/справочные данные
docs/, build.bat, build.ps1, NovaCalc.csproj, app.manifest, .github/workflows/build.yml
```

### Математический движок
Токенизация (Lexer) → парсер рекурсивного спуска с приоритетами: выражение → слагаемые (%) → множители → унарные → степень → постфиксные (!, %) → вызовы/числа/скобки. Унарные ±, функции с аргументами через запятую, константы π/e/Ans, битовые операции, семантика процентов Windows встроена в уровень аддитивных операций. Арифметика на `decimal`.

## Риски и как сняты
- **Прозрачность WinForms нестабильна** → безопасная имитация акрила (градиент + Region), стабильность важнее реальной прозрачности.
- **Дробная арифметика float** → всё на decimal; double только для тригонометрии/логарифмов с округлением вывода.
- **Сборка без Visual Studio** → трёхступенчатый build.bat: MSBuild → dotnet → встроенный csc.exe .NET Framework.
- **Read-only папка данных** → цепочка запасных путей (APPDATA → LOCALAPPDATA → TEMP), записи в try/catch.
- **Нет интернета** → все функции офлайн; сетевой запрос только по кнопке обновления курсов.

## Критерии готовности (все выполнены)
1. Один файл `dist\NovaCalc.exe` (~146 КБ) запускается на чистой Windows 10/11 x64;
2. `NovaCalc.exe --selftest` возвращает 0 (77/77);
3. `0.1+0.2=0.3`, `2+2*2=6`, `(2+2)*2=8`, `200+10%=220` и т.д.;
4. 3 режима, 12 языков, история, настройки, темы, DPI, горячие клавиши;
5. Документация и скрипты сборки в репозитории.
