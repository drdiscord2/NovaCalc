# Resources

Справочные данные NovaCalc встроены в код (без внешних файлов, чтобы релиз оставался одним `NovaCalc.exe`):

- **Переводы интерфейса (12 языков)** — `src/Localization/Strings.cs`.
  Как добавить язык: 1) добавить код в `SupportedLanguages`; 2) дописать перевод в конец каждого `Add(...)`; 3) добавить культуру в `CultureFor`. Fallback — English.
- **Курсы валют по умолчанию** (RUB, USD, EUR, CNY, KZT, BYN, GBP, JPY) — `src/Converters/CurrencyService.cs`; пользовательские значения сохраняются в `rates.json` в папке данных.
- **Категории и коэффициенты единиц, физические константы** — `src/Converters/UnitConverter.cs`.
- **Иконка окна** рисуется программно (GDI+), отдельных `.ico`-файлов нет — это осознанный компромисс ради однофайлового релиза.
